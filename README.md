# Car Price Prediction with Machine Learning

## Project Overview

This project predicts the selling price of used cars using machine learning regression algorithms.

Developed as part of the CodeAlpha Machine Learning Internship.

## Dataset

- Original records: 301
- Records after duplicate removal: 299
- Original features: 9
- Target variable: Selling_Price

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
